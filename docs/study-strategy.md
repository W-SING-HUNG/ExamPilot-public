# 复习策略

本文说明 ExamPilot 采用的复习算法、其学习科学依据、可调参数与已知限制。

## 设计目标

以提高真实考试表现为最高优先级，具体落到四个可度量目标：

1. **覆盖率** — 题库中实际练过的题目比例
2. **正确率** — 已练题目中的答对比例
3. **错题清除** — 答错的题目被复刷到连续答对
4. **结构能力** — 主观题能按采分点组织作答

## 采用的六种方法

### 1. 主动回忆（Active Recall）

先作答、后看解析。`QuestionRunner` 在所有模式下都要求提交答案才揭示结果，主观题要求完整书写而非列要点。

依据：提取练习效应（testing effect）——主动生成答案比重复阅读更能强化长期保持。

### 2. 间隔复习（Spaced Repetition）

答对后复习间隔按 `1 → 2 → 4 → …` 天递增（`interval * ease`），答错立即重置为最短间隔。下次复习时间存入 `records.nextReviewAt`。

客观题与主观题使用**两套独立的间隔规则**：

| | 增长倍率 | 上限 | 理由 |
| --- | --- | --- | --- |
| 客观题 | `ease`（默认 2.0） | 365 天 | 有自动评分反馈，可按标准间隔曲线拉长 |
| 主观题 | 1.5 | 30 天 | 题库无标准答案、无自动评分，不应假设「练过一次就掌握」，因此间隔更短、增长更慢 |

主观题训练**只推进训练次数与复习间隔**：不判对错、不累积正确率、不授予掌握状态。

依据：间隔效应（spacing effect）——分散练习优于集中练习。

### 3. 错题再测（Error-driven Review）

答错的题目权重提高。掌握状态的判定同时看**最近一次作答结果**与累计计数：

- 最近一次答错，且累计答错 ≥ 3 次 → `struggling`（难点）
- 最近一次答对，且净答对（答对次数 − 答错次数）≥ 3 → `mastered`（已掌握）
- 最近一次答对，但净答对不足 3 → `learning`（巩固中）
- 其他情况（含刚答错但累计不足 3 次）→ `learning`

由此保证两件事：

- **`struggling` 不是永久状态**。它表示「最近一次仍然答错，且历史上有累计错误」；再次答对就会离开该状态，恢复有真实作答依据。
- **`mastered` 不会因一次失误而被错误保留**。已掌握后答错会降为 `learning`，间隔归零、立即重新安排，而不是被权重压制到几乎不再出现。

错题本只收录真实答错过的题（`wrongCount > 0`），并按答错次数排序。`wrongCount` 只增不减，历史记录不被改写。

依据：从错误中学习；对未掌握内容的针对性练习效率最高。

### 4. 混合练习（Interleaving）

选题不按知识块连续出题：章节与题型在权重抽样中混合，避免短期重复同一内容造成的「熟练错觉」。

依据：交错练习（interleaving）提升辨析与迁移能力。

### 5. 覆盖均衡（Coverage Balancing）

这是本项目最重要的约束。选题权重中：

- 到期且答错过 → 12
- 到期且未答错过 → 8
- 未到期但答错过 → 6
- 到期且已掌握 → 6
- 从未练过 → 4
- 巩固中且未到期 → 2
- 已掌握且未到期 → 0.3
- 60 秒内刚答过 → 上述权重 × 0.3

因此复习计划始终包含未做题目，**不会退化成只刷错题**；同时到期复习的优先级高于未做题目，**不会退化成只做新题**。

已掌握但**已到期**的题目按正常到期优先级出现（权重 6），只有**未到期**的已掌握题目才被压低（0.3）——「掌握」不等于「永久不再出现」。

依据：覆盖不足是失分的主因之一；只练错题会让大量题目从未被检验，而只做新题会让到期任务无限积压。

### 6. 薄弱点分类诊断（Classified Diagnosis）

薄弱点分为两类，**分别排序、不混排**：

| 类别 | 判定 | 评分 | 排序依据 |
| --- | --- | --- | --- |
| `weak`（待清除） | 已练过，但覆盖率 < 99% 或正确率 < 80% | `覆盖率 × 0.4 + 正确率 × 0.6`（真实值，全错即 0） | 分数升序，越差越前 |
| `uncovered`（未覆盖） | `attempted === 0`，从未练过 | 恒为 0（无正确率数据） | 未练题量降序，缺口越大越前 |

最终榜单最多 6 项：`weak` 全部优先入榜，`uncovered` 用剩余名额补足。

两类不混排的原因：把「已练但全错」和「从未练过」放进同一个加权分数比较，会让其中一类被另一类的数量淹没——一个每道题都答错的章节，不应该因为未练章节更多而被挤出榜单。已暴露的错误比未暴露的未知更紧急。

依据：诊断必须区分「已知的失败」与「未知的缺口」，否则最危险的章节会被隐藏。

## 状态机

```
                      ┌── 答错（累计 < 3）──────────────┐
                      │                                 │
                      ▼                                 │
 new ──首次作答──▶ learning ◀──答错（曾掌握）── mastered │
                      │                                 │
                      └── 答错（累计 ≥ 3）──▶ struggling
                                                  │
                                             再次答对
                                                  │
                                                  ▼
                                            learning ──净答对 ≥ 3──▶ mastered
```

`status` 由 `applyAttempt()` 依据最近一次作答结果与真实计数推导，永不由 UI 直接设置，也不因「未作答」而变化。主观题的 `status` 由 `applySubjectiveAttempt()` 置为 `learning`，**永远不会进入 `mastered` 或 `struggling`**。

## 掌握判定

- **单选题**：所选字母与 `answerNorm` 完全一致
- **多选题**：选项集合与答案集合**完全一致**——错选、漏选、多选均判错
- **判断题**：布尔值与 `answerNorm` 一致
- **主观题**：不自动评分，仅记录「已训练」；AI 评阅单独存档并标注为参考评阅

未作答：`scoreAnswer` 返回 `null`，不计入正确或错误，也不标记为已练。

## 今日计划配额

用户选择的「今日任务量」**只约束客观题名额**；主观题为**额外 1 道**，不占客观题配额，也不会被客观题挤掉。

```
客观题名额  = size
到期配额    = min(到期题数, ceil(名额 × 50%))
错题配额    = min(错题数, ceil(名额 × 25%))
未练配额    = min(未练题数, 名额 − 到期配额 − 错题配额)
未用满的配额按 错题 → 到期 → 未练 顺序回填
```

- **到期优先**：到期题占一半名额，且到期队列按「最久未复习优先」顺序消耗，防止积压无界增长。
- **新用户**：到期与错题为 0 时，未练题补满全部名额，任务量不缩水。
- **题库不足**：计划长度以题库实际可用量为准，**不重复出题、不用主观题充数**，页面如实说明缺口。
- **顺延提示**：排不下的到期题会在页面显示「还有 N 道到期未排入今日任务，将按到期顺序顺延」，不会让用户误以为已清空。
- **同日去重**：今天已练过的题目排在本池末尾，同一天再次生成计划时优先给今天没练过的题；若整池今天都练过，则如实重复而不是缩小计划。

## 可调参数

| 参数 | 位置 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ease` | `scheduler.ts` `DEFAULT_EASE` | 2.0 | 客观题间隔增长倍率，固定不变，答错不降级 |
| `reviewIntervalBase` | 设置页「复习间隔基数」 | 1 | `ease` 的**下限**，对全部客观题写入入口一致生效；实际生效值为 `max(设置值, 2.0)` |
| 主观题间隔 | `scheduler.ts` | 1.5 倍 / 30 天上限 | 固定，不随设置变化 |
| 各权重 | `scheduler.ts` `WEIGHT` | 见上「覆盖均衡」 | 选题偏好 |
| 每日目标题量 | 设置页 | 30 | 仅作展示目标 |

> 「复习间隔基数」不是叠加项，而是 `ease` 的下限。练习、专项、错题复刷、模拟考试四条客观题写入路径都应用同一个下限，因此同一道题在不同模式下的间隔增长曲线一致。
>
> 生效的 `ease` 由**当前设置值**与内置默认值取较大者决定（`max(设置值, 2.0)`），**不由记录中持久化的旧 `ease` 决定**。因此调高设置后训练、再把设置调低，后续间隔会立即跟随调低后的值，不会被之前写入的旧 `ease` 锁死。
>
> 仅在调用方未提供设置值时（例如旧版调用路径或测试），才沿用记录自身携带的 `ease`，且同样不低于内置默认值 2.0。

## 模拟考试

题型、题量、分值、时长、章节范围全部可配置。**未获知正式考试要求时，默认值只是模板，不代表真实考纲。**

交卷后成绩与练习共用同一套记录写入，因此模拟考试既是检验也是训练。主观题作答只累计训练次数与复习间隔，不计入得分。

## 诊断指标

| 指标 | 计算方式 |
| --- | --- |
| 覆盖率 | 已练客观题数 / 本章客观题总数（主观题不计入分母） |
| 正确率 | 答对次数 / 总作答次数（仅客观题） |
| 掌握指数（`weak` 类） | 覆盖率 × 0.4 + 正确率 × 0.6 |
| 薄弱点 | `weak` 类按掌握指数升序全部入榜，`uncovered` 类按未练题量降序补足，合计最多 6 项 |
| 主观题训练进度 | 已训练主观题数 / 主观题总数（只统计「练过」，不统计对错） |

所有指标由真实作答汇总得出。**系统不生成预测成绩，不虚构掌握率，不把缺少数据当作已经掌握。**

## 限制

1. **`ease` 固定**：未实现根据题目难度动态调整的 SM-2 变体；当前实现刻意保持简单可预测。
2. **间隔上限 365 天**：对一学期复习周期足够，但未做长周期验证。
3. **无遗忘曲线建模**：不使用历史遗忘率拟合个体记忆参数。
4. **主观题无自动评分**：题库不提供标准答案，系统拒绝伪造；只能依赖 AI 参考评阅或人工自评。主观题因此永不进入 `mastered`。
5. **诊断基于频次而非认知诊断**：未做知识点级（knowledge tracing）建模，章节粒度是最细诊断单位。
6. **旧数据过渡期**：阶段 2 之前写入的 `status` 不会被重算，保持原值直到该题下次作答；因此历史 `struggling` 记录可能仍显示为难点，直到用户再次作答。
7. **同日去重是偏好而非硬约束**：当某池题目今天全部练过时，计划会如实重复，而不是缩小规模或留空。
8. **单一用户**：无多人数据隔离或云端同步。
