# ExamPilot 网页版设计系统 v2「典藏本」（2026-10-25）

这一版之所以推翻 v1，是因为用户反馈 v1“没有高级感，感觉廉价”。对照通用设计规范复查后，确认 v1 的问题集中在几类常见误区。v1 的具体问题：
- 金色按钮用了渐变，还加了发光，看起来像游戏里的 VIP 标识；
- 数字用了渐变色，徽章做成金属贴纸的质感；
- 小标签全大写并拉开字距，页面信息里大量使用“·”分隔；
- 首页套用了“大数字配进度环再加渐变”的默认模板；
- 内容全被切成同样的圆角卡片，配同样的柔和阴影；
- 每个模块都做了入场上浮，悬停时卡片抬起，指针移过时有扫光，还有持续的呼吸灯；
- 用了毛玻璃，字体全部是系统默认字体。

## 概念
Pro 的视觉原型是一本精装典藏书：深色版像黑色哑光布面，浅色版像象牙色纸张；线条用烫金细线，标题和数字用宋体，当前所在位置用一条书签丝带标示。高级感来自克制：全站只用一种金色，而且只用在细线上；填充一律平涂哑光；用分隔线代替浮起的卡片。

Standard 保持原来干净的无衬线体系，同样不使用渐变按钮、入场动画和悬停抬起。

## 字体
- Pro 的标题、数字和品牌名用宋体：Noto Serif SC 600 字重的子集，包含约 820 个界面用字，woff2 格式 139KB，按 SIL OFL 许可使用。
- 字体只在服务器确认是 Pro 账号后才加载，Standard 用户不会下载。文件名带哈希，按不可变缓存处理。
- 正文仍用系统无衬线字体，保证长时间阅读的舒适度。
- 改了界面文案后，需要重新生成字体子集，方法见 tools/web/ep-serif-LICENSE.txt。

## 版式
- Pro 首页没有包裹框：左侧是宋体问候语、下一步建议和操作按钮；右侧是四个以竖线分隔的“账本”数字，包括覆盖率、正确率、已掌握和待复习，每个都带原来的提示语；最后用一条横线收尾。下方不再重复显示统计卡片。
- 卡片改为平面纸张：只有 1px 线框，没有阴影，圆角 6px。
- 个人中心身份卡做成藏书票样式（金色双线框）；Pro 欢迎页用同样的样式。
- 导航：Pro 用左侧 2px 金色竖线标示当前页，就像书签丝带；Standard 用原来的浅色底块。

## 动效（只回应用户的操作）
- 按下：下沉 1px，120ms。
- 悬停：只变颜色或边框，160ms。
- 导航指示：240ms，只用 transform。
- 弹窗、欢迎页：纯淡入，200–320ms。
- 主题切换：View Transitions 交叉淡化，280ms。
- 去掉了入场编排、悬停抬起、指针扫光、徽章扫光和呼吸灯。
- 减少动态效果模式下，全部动效降到约 0。

## 无障碍
所有文字色在最不利的底色上都要达到 AA 对比度，Standard 原有的绿色和琥珀色已经加深。浅金色不用于小字。焦点环始终可见。
